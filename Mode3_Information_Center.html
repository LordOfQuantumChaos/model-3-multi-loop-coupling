Why this matters

This framework provides a way to study coupled resonator systems while evaluating multiple independent synchronization metrics instead of reducing system behavior to a single measurement.

Mode stability, phase agreement, energy agreement, and energy-balance integrity are scored separately — so “it looks locked” is never mistaken for a complete description of multi-loop behavior.

What this package is

Is

  • Software simulation method for multi-loop lattices of closed driven resonators
  • Arc-masked inter-loop coupling with action–reaction forces
  • Independent metrics for mode-3 stability, phase sync, energy sync, and energy ledger health
  • Drop-in runnable code with unit tests, demo, and short smoke runs
  • Documented production-style config (canonical 3×3, k≈0.006, gate ρ=0.055)

Is not

  • Not a hardware performance warranty
  • Not a claim of universal mode-3 at all couplings or sizes
  • Not “phase lock = energy lock”
  • Not an issued patent (provisional is patent pending only)
  • Not the full AetherMind product or Helix catalog

How it works

  1. Build a lattice of closed driven loops (canonical: 3×3).
  2. Integrate unit dynamics on each loop (pump / limit-cycle style behavior).
  3. Add weak coupling on facing arcs between neighbors (production: velocity-only, k≈0.006).
  4. Score independently: mode-3 stability, phase/pump sync, energy sync, energy-balance integrity.

Run it yourself

Python 3.10+. From a clone of this repository:

python -m venv .venv
# Windows:  .\.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
python -m mode3_coupling demo
python -m mode3_coupling test

Windows: double-click RUN.bat for an interactive menu. Full guide: Drop-in & run · API: API reference
