# What it does **not** do

Honest limits protect scientific integrity and patent language.

| It does **not**… | Correct language instead |
|------------------|---------------------------|
| Guarantee mode-3 on every seed forever | “Under config C, seed set S, frames F, observed rate was R/N.” |
| Warranty hardware performance | “Simulation method / sim metric only.” |
| Equate mode-3 with full sync | Report mode-3, phase lock, and energy lock **separately**. |
| Equate phase lock with energy lock | Evidence shows they often **decouple**. |
| Mean an **issued** patent | Provisional **64/119,833** = patent **pending** only. |
| Include AetherMind chat/HUD product | Separate software surface. |
| Include Helix product catalog claims | Out of this package’s scope. |
| Claim wormholes, vacuum energy, AGI, or exotic products | Out of scope. |
| Replace a classical TMD product story by itself | Related vibration work is a separate path. |
| Prove spacetime manipulation | Conductor/other filings are separate; this package is lattice coupling + metrics. |

## Forbidden shorthand (avoid)

- “Always mode-3.”
- “Fully locked” without defining which metric.
- “Phase lock therefore energy lock.”
- “Patent granted” / “patented” for a provisional.
- “Flight-proven” / “hardware validated” without physical tests.

## Allowed shorthand (prefer)

- “Mode-3 stable under config C at rate R/N seeds.”
- “Patent pending (provisional App. 64/119,833).”
- “Configuration-specific simulation evidence.”
